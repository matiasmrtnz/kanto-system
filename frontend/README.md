# Kanto Systems - Frontend

Frontend del proyecto Kanto Systems desarrollado con SvelteKit.

## Tecnologías
- SvelteKit
- Vite
- JavaScript / TypeScript
- HTML / CSS

---

## Cómo ejecutar el proyecto

### 1. Instalar dependencias
```bash
npm install

2. Levantar servidor de desarrollo
npm run dev

3. Abrir en navegador
http://localhost:5173

Este frontend consume una API en:
    http://localhost:8000
